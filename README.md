# www.unveilui.com

Marketing site for [Unveil](https://www.unveilui.com), by Aryabhatta Labs. Static HTML in `public/`, published to GitHub Pages by `.github/workflows/static.yml` on every push to `main`.

- `public/index.html`: landing page. `public/assets/unveil-launch.*` is the launch video, generated by `scripts/launch-video/build.sh` in the [Unveil repo](https://github.com/ExpenseFlow/Unveil).
- `public/privacy.html`, `terms.html`, `security.html`, `third-party-notices.html`: legal pages, adapted from www.expenseflow.app (same company).
- `public/contact/`: contact form (Formspree, shared with ExpenseFlow; subjects are tagged `[Unveil]`).

DNS lives in Cloudflare (`www` CNAME → `expenseflow.github.io`, proxied). See `Deployment.md` in the Unveil repo.
